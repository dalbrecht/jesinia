RSS

/rss/. Product screen at lower fidelity; it feeds RSS's own spec later. A classic three-pane reader, with marigold only in the title bar: feeds, a Desk-density item list, and a serif reader. Engage a post to open a chat rail with the post as context, then save what matters to the KB.

Default and engaged

  1. Desk density (brief §3): sans list rows with title, one-line excerpt, and source · age; about 8 rows per laptop screen. Unread rows carry a dot and medium weight.
  2. Newsreader is reserved for the reader pane. Lists, sidebar, toolbar and chat stay in the UI sans. The marigold mark is the reader's highlight.
  3. Engage → chat rail. Engage starts a chat with the post as context, docked right (~380px, resizable, pop-out ⧉). Feeds collapse to a rail while it's open. On narrow it's a full-height sheet. The runner comes from Settings; the header picker switches it.
  4. Save to KB writes an augmented page to Sources/ (post text, link, highlights, and optionally the discussion). It confirms inline with a collapsed row linking to the page in Notes.
  5. Engaged items are marked with an "In KB" fern badge in the list, and the smart view "Engaged" collects them.
