States

  1. Chat under the walkthrough is Review's own placement (shell decision 2): questions are usually about the current step, so the chat sits beside the same hunk instead of in a separate rail. The divider resizes it; ⧉ pops it out; ▾ collapses it to its header.
  2. Codex is the default runner in Review, switchable from the chat header. The choice is remembered per app.
  3. The recommendation is advisory. Posting to GitHub is a separate, explicit action behind a confirm step that shows the exact text. Copying the reasoning never posts anything.
  4. Metrics are user-defined, stored per repo. The agent scores them with a one-line rationale each; it does not invent new criteria.
  5. Silhouette: plum header, a wide monospace diff, and a narrow reading-type column stacked over chat. That shape reads as Review even in a Mission Control thumbnail.
