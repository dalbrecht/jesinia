Launcher

/. Foundation screen at higher fidelity. The launcher is how you move between apps (shell decision 1); each app runs as its own PWA window. It also gives a quick check that the KB, sync, and agents are healthy.

IndexLauncherSettingsNotesRSSReviewIssuesMission Control

Default

  1. Tiles open each app in its own PWA window (or a tab if not installed). Built apps show one line of recent activity; unbuilt apps are muted with "Coming soon" and aren't links.
  2. Status strip has three facts: KB, sync, and agents. Each fact has an inline action ("Sync now", "How to fix") that goes to the right Settings section.
  3. Header has the ⌘K palette (search, plus commands like "Open Notes" and "Sync now"), the status dot, and Settings. The greeting line is the one warm touch; it can be turned off.
