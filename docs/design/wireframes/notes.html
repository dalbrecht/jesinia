Notes

/notes/. The tracer app, at the highest fidelity. Browse or search the KB, edit any page in place, talk about it with your agent, and save what matters as a note. It uses every foundation service end to end (spec §11; editing is a Task 5 change, listed in the index).

File tree, editable page, chat

The sidebar is a file tree with a search field above it. The page is always editable: rendered Markdown you type into directly, saved automatically. Chat is a resizable right rail bound to the open page.

  1. File tree (compact density, 24 px rows): folders show page counts. ←→ collapse and expand, ↑↓ move, and Enter opens. "＋" creates a note in the selected folder with an inline name field. Dragging a file moves it; links are rewritten by kb.*, never silently. A small marigold dot marks files Claude changed that you haven't opened since.
  2. No permanent toolbar on desktop. Formatting uses Markdown shortcuts (##, **, - [ ]) and keys (⌘B, ⌘I, ⌘K for link while text is selected). A small floating toolbar appears over selected text. Narrow keeps a toolbar above the keyboard.
  3. Always editable, with no Read/Edit toggle. Markdown renders in place, and syntax markers (##, **, [[ ]]) appear only on the line holding the caret. Typing [[ opens page autocomplete, including "Create". Undo works across the session (⌘Z / ⇧⌘Z).
  4. Autosave: the file is written about 1 s after you stop typing, and on blur or switching pages. The page bar shows "Editing…", then "Saved". The write is atomic and checks the base version, so an external change is caught (see states).
  5. Front-matter becomes a quiet properties line: the id is read-only, tags are editable badges, and "Properties ▸" opens the rest. Provenance comments (jesinia:ai) fold into small chips that can't be edited by accident. They mark the file, not the reading view (brief §8).
  6. External editor stays available under ⋯ ("Open in editor"), because the KB belongs to the files. Chat, pending writes, and Save note work as before.

Search results

Search runs from the field above the tree, and results open as a page in the wide middle column. The tree stays visible, so you can search and browse side by side. Results use compact density, three short lines per hit, built to be skimmed. Opening a hit replaces the results; ⌘[ goes back to them.

  1. Three lines per hit: (1) title in medium weight with the match marked, age right-aligned in tabular figures; (2) folder path, tags, and match count, all muted; (3) one snippet line around the best match. In compact density about 14 hits fit on a laptop screen.
  2. Grouping and scope: title matches first, then content matches, each with a count. "In" limits to a folder (also in:Notes), and sort is Best match, Recently edited, or Folder. Syntax: title:, tag:.
  3. Keyboard: ↓ moves from the field into the results, ↵ opens, ⌘↵ opens in a new window, and Escape clears the search and returns to the open page. ⌘F focuses the field. Notes shows no second search box: ⌘K still opens the command palette (commands and jumping to other apps) from the keyboard.

Save note

"Save note" turns a conversation into a new page: your text plus the agent text you choose to keep. It's your own action, so it writes without a pending-write confirmation (spec §4.3). In the file, kept agent text is wrapped in hidden jesinia:ai provenance comments.
