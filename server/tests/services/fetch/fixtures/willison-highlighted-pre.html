Hello Python 3.15

Python 3.15 is out, and the new unpacking syntax in comprehensions is the feature I expect to reach for most often in everyday code that flattens nested lists.

Unpacking in comprehensions

Here is an illustration lifted from the documentation, with the results shown as comments under each expression so you can see what each one produces:

lists = [[1, 2], [3, 4]]
[*L for L in lists]
# [1, 2, 3, 4]

# equivalent to [x for L in lists for x in L]

And the same idea from the shell, installing the new version with uv first:

# install it
uv python install 3.15

# then run it
uv run --python 3.15 python

Both examples run unchanged on the release candidate, which is a good sign for the final release and for the libraries that will need to adopt the new syntax.
