Why SQLite Is Enough

Most personal tools never outgrow a single file database, and SQLite keeps that file safe with transactions, a write-ahead log and decades of testing behind it.

The write-ahead log lets readers keep reading while one writer commits, which is exactly the shape of a feed reader polling in the background.

Backups are a file copy away, and the format is stable enough to outlive the tool that wrote it, which matters for anything you want to keep for years.

A sneaky link sits next to the closing remarks so the extractor has to keep its text but never the script it points to.
