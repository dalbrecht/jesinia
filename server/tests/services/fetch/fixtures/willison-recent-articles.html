Notes on running local models with a long context

I spent the weekend running local models against long documents to see how far the context window really stretches on a laptop with a reasonable amount of memory.

The short version: it works far better than it did a year ago, but the KV cache is still the thing that runs out first, long before the model weights themselves become the problem.

Here is the command I used to load a model with a large context:

cat notes/*.md | \
  llm -m local-model --option context 131072 'summarize this'

Memory climbed steadily as the prompt grew, and generation slowed down once the cache no longer fit in the faster tier of memory on the machine.

I expect this to keep improving quickly, and I will keep notes here as it does.
